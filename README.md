# JapanStockMonitor

WPF と SQLite を利用して開発した日本株モニターアプリです。
株価確認、評価額計算、お気に入り登録、CSV出力などの機能を実装しました。

---

## 使用技術

* C#
* WPF
* SQLite
* LiveCharts
* Alpha Vantage API
* Git / GitHub

---

## 主な機能

* 日本株価表示
* 株価チャート表示
* 評価額計算
* SQLite 履歴保存
* CSV出力
* お気に入り機能
* ダークモード
* 自動更新機能
* API連携による株価取得

---

## 開発目的

WPF の UI開発、SQLite DB連携、API通信などを学習するために制作しました。
実際のアプリケーション開発を意識して、機能追加とコード整理を行いました。
